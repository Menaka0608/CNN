# CNN

This project demonstrates a Convolutional Neural Network (CNN) using Python and Jupyter Notebook.

## Project Overview

The project uses a CNN model for image classification using deep learning techniques.

## Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- TensorFlow
- Keras

## Deep Learning Algorithm

Convolutional Neural Network (CNN)

## Project Workflow

1. Load the dataset
2. Preprocess the images
3. Split the data into training and testing sets
4. Build the CNN model
5. Train the model
6. Evaluate the model
7. Visualize the results
